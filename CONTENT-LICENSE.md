## Why it is like this

Math Dojo is free on purpose. It exists so that anyone can practise without an account, a payment,
or an install, and that is the whole point of it.

The code is a gift: take it, learn from it, build your own thing with it. But the content is the
part that took the longest and can't be regenerated — 480 problems written by hand in three
languages, and a curriculum sequenced so each step is small enough to take alone. Reserving it is
what stops someone from putting a paywall in front of work that was given away, which would break
the promise made to everyone already using it.

If you want to build a maths game: please do, and the code is right there to start from. Write your
own problems, and it's yours.
